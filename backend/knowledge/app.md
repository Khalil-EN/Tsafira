# App Overview

The application is a social community application.

Users can create accounts and maintain profiles.

Users can add other users as friends.

Users can send and accept friend requests.

Users can participate in communities.

Communities have owners, administrators, moderators and regular members.

Users can communicate through direct conversations and community conversations.

The application contains a chat section where users can communicate with other users.

The application also provides an AI assistant that can answer questions about the application and provide travel-related information.

# Friends

Users can send friend requests to other users.

After a friend request is accepted, the users become friends.

Friends can communicate through direct conversations.

# Communities

A community has an owner.

A community can contain administrators, moderators and regular members.

If the owner leaves, ownership can be transferred to another active member according to the application's ownership rules.

# Chat

Users can access their conversations from the chat section.

Users can send text messages.

Messages contain the sender, conversation, content and creation date.

The AI assistant has its own conversation for each user.
